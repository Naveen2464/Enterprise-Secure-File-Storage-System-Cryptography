# Team tasks and deliverables

| Team member | Workstream | Main deliverables |
|---|---|---|
| 1 | Cryptography and key management | AES-GCM implementation, RSA-OAEP wrapping, RSA-PSS signing, Key Vault key operations, rotation plan |
| 2 | Backend and database | FastAPI service layer, PostgreSQL schema/migrations, Blob Storage upload/download |
| 3 | Identity and access control | Entra ID sign-in/MFA, JWT validation, application RBAC, access-control tests |
| 4 | Frontend, monitoring and QA | Streamlit/API integration, audit logging, Azure Monitor, end-to-end tests, report and demo |

Each member should commit their work to a shared feature branch and document the interfaces they expose. Merge only after tests pass.
